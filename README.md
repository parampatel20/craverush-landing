## Getting Started

### Prerequisites

- A modern web browser
- `<Node.js 18+ and npm, only if the project uses a build step>`

### Installation

```bash
# Clone the repository
git clone https://github.com/parampatel20/craverush-landing.git

# Move into the project folder
cd craverush-landing
```

### Run locally

**Static site:** open `index.html` in your browser, or serve it with a local server:

```bash
npx serve .
```

**With a build step (if applicable):**

```bash
npm install
npm run dev
```

## Deployment

The site can be deployed to any static host:

- **GitHub Pages:** Settings → Pages → select the `main` branch
- **Vercel / Netlify:** import the repository and deploy with default settings

## Customization

- **Text and copy:** edit `index.html`
- **Colors and fonts:** edit the variables at the top of `css/style.css`
- **Images:** replace files in the `images/` folder, keeping the same filenames
